# Contributing

Shared protocols, Git storage, launch tools and conformance support belong in this repository. Application-specific features belong in the relevant application submodule. Explain the problem, affected consumers and validation evidence; coordinate incompatible package changes with both applications before updating their pinned revisions.

The project-authored material is offered under the [MIT licence](LICENSE), with [scope and exceptions](LICENSE.md). By intentionally submitting original work for incorporation, you offer it under MIT while retaining your copyright. Identify any third-party material, its source, licence and your authority to contribute it. Do not include private runtime data, credentials or signing keys in source changes.

Add your preferred contributor name or organization and a short contribution description to [CONTRIBUTORS.md](CONTRIBUTORS.md) when your work is incorporated. Preserve existing author and third-party notices. Contributions to a distributable Python package also update its packaged contributor list so attribution travels with the distribution.
